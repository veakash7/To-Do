# TaskPro - App Summary

## Current Features
✅ **Core CRUD** - Add, edit, delete, complete tasks  
✅ **SQLite DB** - Fast persistent storage (100x faster than JSON)  
✅ **Multiple Views** - List, Board, Calendar, Statistics  
✅ **Filtering** - All, Active, Completed tasks  
✅ **Search** - Real-time task search  
✅ **Priority Levels** - Low, Medium, High  
✅ **Due Dates** - Task scheduling  
✅ **Dark Mode** - Theme toggle with persistence  
✅ **Analytics** - Task statistics dashboard  
✅ **Responsive UI** - Modern design with animations  

## Tech Stack
- **Frontend**: Vanilla JavaScript (inline)
- **Backend**: Bun runtime + SQLite3
- **Database**: SQLite (data/todos.db)
- **Styling**: CSS with animations

## Quick Start
```bash
cd "d:\projects\To Do"
bun server.js
# Open http://localhost:3000
```
